# 리테일사업팀 브리핑

| 문서 | 파일 | 대상 |
|---|---|---|
| 팀 브리핑 (공지용) | `index.html` | 팀 전체 공지 |
| 온보딩 브리핑 (수습용) | `onboarding.html` | 신규 입사자 |

## 주의

내부 공유용 문서입니다. 매출·공헌이익 실적과 미공개 IP 협업 정보가 포함되어 있습니다.
GitHub Pages(무료 플랜)는 공개 호스팅이므로 URL을 아는 누구나 접근할 수 있습니다.
검색엔진 차단(`noindex`) 태그가 적용되어 있으나 완전한 접근 제어는 아닙니다.

## GitHub Pages 배포

1. 새 저장소 생성
2. `index.html`, `onboarding.html` 업로드
3. Settings → Pages → Source: `main` 브랜치 / `/ (root)` 선택
4. 1~2분 후 `https://<사용자명>.github.io/<저장소명>/` 접속

## 링크

- 공지용: `https://<사용자명>.github.io/<저장소명>/`
- 수습용: `https://<사용자명>.github.io/<저장소명>/onboarding.html`
